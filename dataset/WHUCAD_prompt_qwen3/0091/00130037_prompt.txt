Create a base shape by sketching four lines on the XY plane with a width of 95mm and height of 20mm, then extrude it 2mm to form a solid body. Add a chamfer to the edge. On the same plane, sketch another set of four lines forming a 24mm by 95mm rectangle and extrude it 2mm to create a second body. Repeat the sketch and extrusion process one more time to form a third body.
