Create a base shape by sketching four lines on the XY plane with a width of 95mm and height of 15mm, then extrude it 3mm to form a solid. Chamfer the edges of this extrusion. On the same XY plane, sketch another set of four lines forming a 20mm wide by 95mm tall rectangle, extrude it 2mm to create a second solid, and repeat the process for a third identical sketch and extrusion.
