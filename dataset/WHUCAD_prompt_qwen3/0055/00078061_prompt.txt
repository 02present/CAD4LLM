Create a base shape by sketching a 95mm wide and 39mm tall rectangle on the XY plane, then extrude it 1mm. Add a second extrusion of a 10mm wide and 95mm tall feature also 1mm deep. Chamfer the edges of both extrusions. Sketch additional features on the XY plane with varying dimensions and extrude them 1mm each, finally chamfer the last set of edges.
