Create a base shape by sketching four lines on the XY plane with dimensions 6mm by 95mm and extruding it 4mm. Then, add two chamfers to the edges. On the same plane, sketch another set of four lines forming a 95mm by 4mm rectangle and extrude it 2mm. Repeat this process for a third sketch, extruding 2mm, and create two revolved features from subsequent sketches. Finally, add a smaller sketch along the length and extrude it 2mm to complete the design.
