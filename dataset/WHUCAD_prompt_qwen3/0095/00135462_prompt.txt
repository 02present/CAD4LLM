Create a base shape by extruding a sketch on the XY plane with a 95mm width and 48mm height 6mm upwards. Then, create a larger vertical section by extruding another sketch on the same plane with a 95mm width and 95mm height 122mm upwards. Repeat this pattern on both sides of the base, alternating between 48mm and 95mm widths, and extrude each sketch 6mm and 122mm accordingly.
