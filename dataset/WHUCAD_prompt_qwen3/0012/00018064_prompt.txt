Create a base shape by extruding a sketch with four lines on the XY plane, 7mm wide and 95mm tall, 5mm deep. Chamfer the edges of this base. Then, add three more extrusions using smaller sketches on the same plane, each with different widths and depths: 4mm wide, 2mm deep; 95mm wide, 1mm deep; and finally a large 95mm wide by 96mm deep extrusion.
