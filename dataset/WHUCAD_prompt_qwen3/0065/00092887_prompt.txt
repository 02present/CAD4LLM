Create a symmetrical part by first sketching a circle on the XY plane with a diameter of about 20mm and extruding it 96mm to form a cylinder. Repeat this process for another circle slightly offset vertically, creating a second cylinder of the same size. Then chamfer both ends of the cylinders. Finally, add three more smaller circles along the central axis and extrude each 16mm to create shorter cylindrical features around the main body.
