Then, on the same plane, sketch five connected lines and arcs forming a complex profile and extrude it 34 mm to create a second feature. Repeat this process for two more sketches, each extruded 34 mm, to build up the main structure. Finally, chamfer the edges where the features meet to refine the overall shape.
