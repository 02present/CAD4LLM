Create a base shape by extruding a circle with a diameter of about 4mm along the Z-axis for 3mm. Then, on the same plane, draw eight lines forming a grid and extrude them 3mm to create a second feature. Repeat this process to add three more extruded features, each based on a new set of lines, and finally add a small circular protrusion at the center by extruding another circle 3mm in height.
