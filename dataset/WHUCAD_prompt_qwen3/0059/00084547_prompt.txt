Create a base shape by sketching eight lines on the XY plane with a width of 95mm and height of 14mm, then extrude it 16mm to form a solid body. Chamfer the edges of this body. On the same plane, sketch four lines forming a new shape, offset downward, and extrude it 16mm to create a second solid body. Repeat the process one more time with a different sketch layout to form a third extruded body.
