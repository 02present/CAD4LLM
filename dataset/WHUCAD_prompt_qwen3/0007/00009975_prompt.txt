Create a base shape by sketching a circle on the XY plane with a bounding box from [0.0, -48.0, 96.0, 48.0], then extrude it 24 mm to form the first body. Repeat this process twice more, extruding 72 mm and 44 mm respectively, each time using a new circle sketch on the same plane. Chamfer the edges of the first extrusion.
