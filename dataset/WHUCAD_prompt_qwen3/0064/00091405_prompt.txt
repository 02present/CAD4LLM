Create a base shape by sketching four lines on the XY plane with a width of 95mm and height of 3mm, then extrude it 29mm to form the first body. Next, sketch twelve lines on the same plane with a larger height of 21mm and extrude them 3mm to create a second body. Chamfer the edges of the first body. Continue by sketching progressively taller profiles and extruding each 125mm to build up the main structure.
