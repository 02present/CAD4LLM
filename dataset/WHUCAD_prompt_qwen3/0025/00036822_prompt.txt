Create a base shape by sketching four lines on the XY plane with a width of 12mm and height of 95mm, then extrude it 1mm to form a solid. Chamfer the edges of this extrusion. On the same plane, sketch eight lines forming a smaller structure below the first sketch, extrude it 1mm to create a separate feature. Repeat this process for another sketch with six lines, extruding it 1mm as well. Finally, revolve the last sketch around an axis to complete the design.
